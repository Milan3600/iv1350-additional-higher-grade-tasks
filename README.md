# IV1350 – Object Oriented Design  
## Additional Higher Grade Tasks  

This repository contains the solutions for all three Additional Higher Grade Tasks in the IV1350 course.

The repository contains two Java projects:

### bikeRepairAHGT
Builds on the Repair Electric Bike application developed during the seminars and includes:
- Task 1 – Implementation of the Template Method design pattern for repair order observers
- Task 3 – Unit tests for all methods that print to `System.out`

### inheritancecomposition
Contains the solution for:
- Task 2 – Adapting a Java library class using both inheritance and composition
